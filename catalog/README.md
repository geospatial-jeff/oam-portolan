# OpenAerialMap (Portolan mirror)

![OpenAerialMap](https://img.shields.io/badge/OpenAerialMap-blue) ![aerial imagery](https://img.shields.io/badge/aerial_imagery-blue) ![drone](https://img.shields.io/badge/drone-blue) ![UAV](https://img.shields.io/badge/UAV-blue) ![satellite](https://img.shields.io/badge/satellite-blue) ![orthomosaic](https://img.shields.io/badge/orthomosaic-blue) ![humanitarian](https://img.shields.io/badge/humanitarian-blue) ![HOT](https://img.shields.io/badge/HOT-blue)

A static, cloud-native mirror of the 21,863 scenes in [OpenAerialMap](https://imagery.hotosm.org/), the open satellite, aircraft and drone imagery service run by the [Humanitarian OpenStreetMap Team](https://www.hotosm.org/). Every scene is a STAC item that points at its Cloud Optimized GeoTIFF on OpenAerialMap's own storage, so no imagery is copied. Scenes are split into three collections by license, because OpenAerialMap licenses each image separately: CC BY 4.0, CC BY-SA 4.0 and CC BY-NC 4.0. Each collection publishes an items.parquet index for searching every scene in one read. Agents start at [AGENTS.md](https://source.coop/geospatialjeff/oam-portolan/AGENTS.md).
