## Known Issues

- This is a snapshot taken 2026-10-06T17:48:03Z. OpenAerialMap adds roughly 100 scenes a month; check the upstream STAC API for newer scenes.
- The gsd property is not reliable for every scene. Across the catalog, 114 of the 115 items with gsd below 0.0001 are EPSG:4326 COGs, so their gsd is in degrees. In this collection 2 have gsd of 10 or more, up to 30. Filter on gsd with care.
- No item in this collection starts before 1990. 0 scenes have bounding boxes wider than 20 degrees, which inflates the collection extent.
- Older COGs have no mask. In a random sample of 40 scenes, 16 had no internal mask and 5 had no embedded band statistics. Render older scenes with nodata=0 to hide black borders.
- file:checksum is published upstream only for recent uploads, and file:size only for the COG. This mirror does not compute missing values for bytes it does not host.
- OpenAerialMap's bucket answers simple GET requests with Access-Control-Allow-Origin: *, but on 2026-10-06 it rejected a CORS preflight that asked to send a Range header (HTTP 403). Browser clients whose range reads need a preflight cannot read the COGs directly; server-side readers such as GDAL are unaffected.
